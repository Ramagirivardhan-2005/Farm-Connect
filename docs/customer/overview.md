# Customer Role — Platform Overview

The **Customer** role on FarmConnect enables consumers to discover verified agricultural channels, subscribe to family farms, view morning harvest availability, place orders directly with farms, track deliveries via real-time GPS/state progression, and pay through an escrow-backed Secure Purse.

## Core Customer Capabilities
1. **Direct Discovery**: Access verified farmer channels ranked by Bayesian quality metrics, distance, and genuine organic certificates.
2. **Subscription & Pinning**: Subscribe to favorite farms to receive priority harvest alerts and pinned dashboard access.
3. **Transparent Stock Cards**: View actual available harvest weight (KG/Units) rather than static inventory tables.
4. **Multi-Farm Cart**: Purchase produce from multiple farmers with split fulfillment tracking.
5. **Cold-Chain Tracking**: Monitor real-time transit status through an interactive 10-point dispatch timeline.
6. **Secure Purse**: Escrow digital wallet providing zero-fee instant checkout and instant harvest adjustments.
7. **Channel Promotion to Farmer**: Any verified customer can apply to create their own FarmConnect Channel using their existing account without re-registering.
